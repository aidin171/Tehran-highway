# اتوبان تهران 🚗
 <a href="https://pcrama.ir/game/tehran-highway/">دمو بازی</a> <br>
بازی رانندگی سه‌بعدی و رایگان تحت وب با فضای ایرانی. با پیکان، پراید یا پژو ۲۰۶ در اتوبان تهران برو؛ از ترافیک جا خالی بده، از کنار برج آزادی و برج میلاد رد شو، جریمه‌ی دوربین نده و مراقب راننده‌ی خلاف‌رو باش!

## ویژگی‌ها
- گرافیک سه‌بعدی واقعی (WebGL / Three.js): چرخه‌ی غروب، شب، سپیده‌دم و روز، بازتاب آسمان روی بدنه، چراغ‌های جلو، درخشش و تاری حرکت
- ماشین‌های ایرانی با مدل سه‌بعدی واقعی (FBX): پراید ۱۳۲، نسیم، تندر ۹۰، پژو ۲۰۶، پژو ۴۰۵ (سمند و تاکسی)، زامیاد؛ و پیکان، اتوبوس BRT، کامیون و موتور که با کد ساخته شده‌اند
- ترافیک هوشمند با راهنما و ترمز، موتوری‌های بی‌قاعده، لاین مقابل و راننده‌ی خلاف‌رو
- دوربین کنترل سرعت (۱۰۰ کیلومتر بر ساعت): آهسته برو تا جریمه نشوی
- بنزین، نیترو، تعمیر، کمبو و جا خالی (ریسک)
- صدای موتور با دنده، موسیقی با گام دستگاهی، دو نمای دوربین، توقف، ذخیره‌ی رکورد و اشتراک‌گذاری امتیاز

## کنترل
| | کامپیوتر | موبایل |
|---|---|---|
| فرمان | `←` `→` یا `A` `D` | لمس نیمه‌ی چپ یا راست صفحه |
| نیترو | `Space` یا `↑` | دکمه‌ی نیترو |
| ترمز | `↓` یا `S` | دکمه‌ی ترمز |
| دوربین | `C` | 📷 |
| توقف / صدا | `P` / `M` | ⏸ / 🔊 |

## اجرا
بازی به اینترنت نیاز دارد (Three.js و فونت وزیرمتن از CDN). با یک سرور محلی اجرا کن:

```bash
python3 -m http.server 8000
```

سپس `http://localhost:8000` را باز کن.

## انتشار روی GitHub Pages
1. یک ریپازیتوری عمومی بساز و `index.html` و `README.md` را آپلود کن.
2. از **Settings → Pages** شاخه‌ی `main` و پوشه‌ی `/ (root)` را انتخاب کن.
3. بعد از چند دقیقه بازی در `https://USERNAME.github.io/REPO/` در دسترس است.

## ساختار فایل‌ها
```
index.html
README.md
models/
  132.fbx  nasim.fbx  l90.fbx  p206.fbx  p405.fbx  zamyad.fbx
```
پوشه‌ی `models` باید کنار `index.html` آپلود شود. اگر مدل‌ها لود نشوند، بازی با ماشین‌های ساخته‌شده با کد اجرا می‌شود.

## ساخت
